# 👗 Interactive Dopamine Dressing Landing Page

## 🌍 About the Project
A playful fashion interface built as a SheCodes Basic Add-On final project. Users can mix and match wardrobe colours with vibrant gradients, CSS effects, and interactive styling for a fun, dopamine-boosting experience.
